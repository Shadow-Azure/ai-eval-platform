case 回调路由残留 runner 面 token 依赖（修复于 PR 内）

现象
RUNNER_HEARTBEAT_TOKEN 配置后，平台短期 token 的 started 回调被 401（require_runner_token 先于 require_case_token 执行）。
修复
移除 case 路由的 require_runner_token；case 端点只认 RUNNER_TASK_SECRET 配置下的平台签发 token（M2-04 遗留 b 收口）；新增统一鉴权测试。
FIXED（commit 204fc91，重部署后 PASS）
P1

SigV4 X-Amz-Credential 斜杠未编码（修复于 PR 内）

现象
预签名 PUT 被真实 MinIO 拒签（SignatureDoesNotMatch 403）——规范查询串中凭据值的 scope 斜杠必须编码为 %2F。
修复
canonical 查询与最终 URL 统一使用编码后的凭据值；对象存储测试新增 X-Amz-Credential=ak%2F… 断言。
FIXED（commit 5d0fc02，重部署后 PASS）
