## §1 一页速览

一句话：把轨迹页左栏从“会话树 + 两张常驻卡片”改成“顶部会话下拉 + 两个可折叠抽屉”，让高频的会话切换和关键节点导航先出现，低频的原始文件默认收起。

比喻：原来的左栏像一张桌子上摊开的四张纸——会话树、关键节点、原始文件、页脚，想找会话得先绕过关键节点；现在把会话收进一个抽屉按钮，关键节点留在桌面，原始文件关进第二个抽屉。

## §2 架构导览

### 2.1 页面装配

`TracePage` 仍是单页容器；本次只替换左栏内部组件与两个本地 state：

```text
TracePage
  ├─ TraceOverview
  ├─ SessionSelect（桌面左栏 / 移动端顶部复用）
  ├─ PhaseNav（包在 hidden 容器里）
  ├─ ConversationView / StepList / Timeline
  ├─ Inspector
  └─ RawSource（文件列表 + 打包下载，默认 hidden）
```

### 2.2 会话分类

`traceSessionRole(session, unlinked)` 是纯函数：`unlinked=true` 或 `status === "unlinked"` 返回 `"unlinked"`；有 `parent_session_id` 返回 `"subagent"`；否则 `"main"`。`unlinked` 参数来自 `flattenSessionTree` 的 `flat.unlinked`，所以“父会话缺失但 status 仍是 ready”的孤儿会话也会被标为未关联，不会被误认为主 Agent。

### 2.3 状态与联动

`selectSession` 仍走既有 URL 作为选中态：更新 `session`、清空 `span`/`kind`，触发 spans query；`phasesOpen` 与 `sourcesOpen` 只是视图折叠，不进入 URL、不改变数据口径。两个 section 的标题是 `<button>`，带 `aria-expanded` / `aria-controls`，内容始终渲染并用 `hidden` 控制可见性，因此 `aria-controls` 的目标始终存在。

## §3 数据流走查

1. 打开 `/evals/:runId/cases/:caseRunId/trace?attempt=1&session=<main>`。
2. `fetchAttemptTrace` 返回 `sessions` 树；`flattenSessionTree` 得到 `linked` / `unlinked` / `defaultSessionId`。
3. `allSessions` 合并 linked + unlinked；`unlinkedIds` 标记未关联集合；`selectedSession` 先按 URL `session` 选，找不到再回退 `defaultSessionId`。
4. `SessionSelect` 用选项显示角色、名称、原生 `native_session_id`、span 数；默认选中项来自 `selectedSessionId`，所以 URL 直达子会话时下拉也显示子会话。
5. 选择新 session -> `selectSession` 清空 span/kind -> `fetchTraceSessionSpans` 重新取该会话 spans -> 中间轨迹与右侧详情更新。
6. 点击关键节点标题只切换 `phasesOpen`；点击原始文件标题只切换 `sourcesOpen`；文件下载与导出仍调用原有 mutation。

## §6 讨论点

### 6.1 230px 左栏中完整 sessionId 换行

- **位置**：`web/src/styles/trace-viewer.css:390`（`.trace-session-select-id`），`web/src/pages/TracePage.tsx:295`。
- **现象**：sessionId 是 36 字符 UUID，在 230px 左栏里会折成两行，选择器高度约 55px。
- **问题**：完整值可见与左栏紧凑存在取舍；如果把 ID 截断，用户仍要悬停或看右侧详情。
- **预判**：保留完整值并允许换行更符合本次“选中会话显示 sessionId”的目标；如果后续觉得左栏过高，可以改为两行布局或加大左栏宽度，不建议退回截断。
- **结论**：（待用户拍板）

### 6.2 原型的会话切换只更新标识

- **位置**：`prototype/trace-viewer-redesign/index.html:1531`（`SESSION_DATA`）与 `:1572`。
- **现象**：原型选择子 Agent 后只更新角色、名称、sessionId；中间对话与右栏仍是主 Agent 的静态内容。
- **问题**：原型是交互方向确认稿，不是完整数据驱动页面；但用户可能误以为切换后数据会重排。
- **预判**：在原型 README 已注明“切换只更新会话标识，生产实现按真实 span 重取”；可接受。若要求原型也完整重渲，需要引入第二份轨迹数据，成本大于本次方向确认价值。
- **结论**：（待用户拍板）

### 6.3 原型文件首次入库

- **位置**：`prototype/trace-viewer-redesign/index.html`（新增 1607 行）。
- **现象**：此前该原型是本地未跟踪文件，只通过 release 分发；本次第一次进入仓库，PR 行数因此显著增加。
- **问题**：评审成本上升；但如果不入库，就无法在仓库内核对 UI 与原型的一致性。
- **预判**：入库是值得的，且文件是单文件静态原型、无外部依赖；后续应把它作为轨迹页设计的唯一入口，旧的三栏原型只作历史对照。
- **结论**：（待用户拍板）

## §9 文件级代码分析

### 9.1 `web/src/pages/TracePage.tsx`（M）

职责：轨迹页容器；本次把 `SessionList` 替换为 `SessionSelect`，并把两个 section 标题改成可折叠按钮。

- 旧：`SessionList` 用 `linked`/`unlinked` 两组树形 `button`，选中态来自 `selectedId`，子会话靠缩进表示。
- 新：`SessionSelect` 用 AntD `Select`，选项 label 是两行结构（角色 + 名称 / sessionId），`optionRender` 用 `span` 组合角色、名称、span 数和运行类型；`selectSession` 仍复用原有 URL 选中逻辑。实现思路：把“树”压成“单值选择器”，把会话数量与类型信息放进选项，降低左栏高度。
- 折叠块：`phasesOpen` 默认 true，`sourcesOpen` 默认 false；`hidden` 控制显隐，标题按钮带 `aria-expanded`/`aria-controls`。实现思路：折叠只影响视图，不改变 URL 与查询。

### 9.2 `web/src/features/traces/traceModel.ts`（M）

职责：会话分类纯函数。`traceSessionRole` 只依赖 `parent_session_id`、`status` 与显式 `unlinked` 标记，不读 React/样式。测试覆盖 root、child、orphan 与显式 unlinked 四种输入。

### 9.3 `web/src/styles/trace-viewer.css`（M）

职责：左栏会话选择器、角色徽标、折叠标题与 chevron 的视觉。关键点：

- `.trace-session-select.ant-select-single { height: auto; }` 与 `.ant-select-selector { height: auto !important; }` 解决 AntD 单行 Select 固定 32px 高度导致 sessionId 第二行被裁切的问题。
- `.trace-session-select .ant-select-selection-item { white-space: normal; overflow: visible; }` 让完整 UUID 换行可见。
- `.trace-pane-section-toggle { font-family: inherit; }` 保留原有 9px 大写标题字号；不要用 `font: inherit`，否则会覆盖 `.trace-pane-section-head` 的字号。
- 900px 以下隐藏 `.trace-session-picker`，移动端继续用顶部 `.trace-mobile-session-picker`。

### 9.4 `tests/trace-viewer-model.test.mjs`（M）

新增一条分类测试，覆盖 `main`、`subagent`、`unlinked`、显式 unlinked。没有新增 React 渲染测试，原因见 §7。

### 9.5 原型（A）

`prototype/trace-viewer-redesign/index.html` 是单文件静态原型：左栏用自定义下拉（`session-select` + `session-menu`），三个选项分别代表主 Agent、子 Agent、未关联；关键节点和原始文件用 `hidden` + `aria-expanded` 切换。`session-select` 的 `overflow: visible` 覆盖保证下拉菜单不被 `.pane` 裁切；菜单宽 300px，避免 190px 左栏里 UUID 折得太碎。

### 9.6 设计文档（M）

`02` §3.7 与 `09` §5.3 从“左会话树 + waterfall”更新为“会话下拉 + 关键节点 + 对话轨迹/时间线 + span 详情 + 原始文件折叠”，与 #182 的对话视图和本次 #294 的交互一致。旧三栏原型在 `prototype/README.md` 标注为历史对照。
